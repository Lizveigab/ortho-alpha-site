# Ortho Alpha — prévia React

Esta é uma prévia React/Vite independente do site HTML existente. É publicada sob `/ortho-alpha-site/react/` por GitHub Actions, mantendo a raiz (`/ortho-alpha-site/`) e o domínio oficial inalterados.

Comandos: `npm install`, `npm run dev`, `npm run build`.

As fotos institucionais são copiadas do diretório `assets/` existente no repositório. A navegação usa hash routes (`#/sobre`, `#/especialidades/...`) para permitir acesso a páginas internas no GitHub Pages. O Instagram é uma galeria, não feed sincronizado. O conteúdo é prévia e não possui integração com o Supabase ou formulário de contato.
